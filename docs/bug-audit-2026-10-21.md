# Agent scrolling and interaction audit — 2026-10-21

> **Historical record.** This audit describes the daemon-based 0.3.1 baseline
> and the 0.3.2 fixes. FACT is now a single process with no daemon, IPC or
> persistence, and the daemon/TUI test harnesses mentioned below no longer exist.
> See [testing.md](testing.md) for current coverage.

Tested baseline: main at `84493b0` (FACT 0.3.1). Fix version: 0.3.2.

## Reproduced failures and causes

| Failure | Cause | Fix and evidence |
| --- | --- | --- |
| Wheel changes agent prompt history instead of paging its transcript | `send_app_wheel` converted wheel input to Up/Down for alternate-screen apps without mouse reporting. | Real-ConPTY keyboard fixture received `UpArrow` before the fix. It now requires `PageUp`; wheel fallback sends PageUp/PageDown. Apps still determine what those keys do. |
| App mouse buttons do nothing in drag tracking mode | Click handling tested only `MOUSE_CLICK`. Alacritty exposes modes 1000, 1002 and 1003 as mutually exclusive flags. | The streaming fixture requested 1002. Its wheel worked, but left press never arrived before the fix. All three tracking flags now route button input; real wheel/press/drag/release assertions pass. |
| Redrawing agent output moves text under a selection | Selection stored screen coordinates and copied from the continually replaced live cell buffer. | Selection now owns a viewport snapshot, used for both rendering and copy. A timer-driven ConPTY fixture checks stable display while output continues and live updates after Esc. A unit test mutates the live cells and checks the original selected text is copied. |

## Related defects found in review

- All forwarded mouse events previously used SGR encoding even if the app had
  not enabled mode 1006. Reports now honor SGR or legacy X11 encoding, with unit
  coverage for buttons, motion, wheel, modifiers and legacy coordinate limits.
- Mouse release on the tab strip returned before completing the child gesture.
  Release is now routed to its originating pane with clamped coordinates before
  tab hit testing. Middle and right drags and all-motion tracking are supported.
  Each held button retains its own originating pane during overlapping gestures.
- Synthesized rail events that exceed legacy encoding's coordinate limit fall
  back to page keys, so unusually wide panes do not lose their scroll action.
- Shift bypassed app capture for left selection but not the context menu.
  Shift+right-click now opens FACT's menu.
  The selection hint follows the configured copy shortcut. Configured bindings
  and prefix cancellation retain their existing precedence over selection keys.
- In main-screen mouse apps, forwarding pointer motion after Shift+wheel would
  run the daemon's normal input path and reset scrollback to live output. While
  viewing history, pointer motion stays local and dragging selects history text.
  The main-screen ConPTY fixture covers scrolling, motion and local selection.
- The event reader used an unbounded frame queue and the UI drained it without
  a turn limit. An eight-message ordered queue and bounded input/event batches
  keep memory and per-turn work bounded without dropping delta frames.
- A rail page sent five synchronous requests. It now sends one request containing
  five wheel reports, reducing work during repeated scrollbar drags.

Mouse reporting follows the [xterm control sequence specification](https://invisible-island.net/xterm/ctlseqs/ctlseqs.html).

## Scope and limits

Reviewed client input, rendering and frame processing; terminal mode reporting;
daemon input, scroll and frame fan-out; startup/installation; and existing tests
for persistence, IPC, shell lifecycle, layouts and configuration. Verification
uses isolated data directories and real Windows ConPTY processes.

The deterministic fixtures exercise the terminal protocols without using an AI
account or sending prompts. This does not establish compatibility with every
version of every agent. Alternate-screen apps own their transcript; FACT cannot
recover text that an app never renders or stores. Inline modes remain available
for FACT-owned history and search. A passing audit cannot guarantee that the
whole application has no undiscovered defects.
