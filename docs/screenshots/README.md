# README screenshots

These images show FACT 0.3.3 running in real Windows ConPTY sessions. The
original capture drove eight independent PowerShell processes, the actual
keyboard and mouse controls, and recorded the resulting terminal cell grid. The
PNG renderer preserves that content and its colors using Consolas and adds only
black padding, with no invented window frame. PIDs and shell versions reflect the
capture machine. The demo deliberately configures a `Ctrl+B` prefix for its
driven input; the default is `Ctrl+Space`.

The pane menu shown here is now opened with `Shift`+right-click, because plain
right-click copies or pastes. The menu contents and the rest of the workspace
layout are unchanged.

The history example generates numbered lines locally. No model request, agent
conversation, clipboard content or personal session is used.

These are reviewed documentation assets, not generated by the test suite. The
scripted TUI capture harness was removed together with the daemon-based test
suite. Update the PNGs manually only when the visible workspace changes, and
review each image before committing it.
