# README screenshots

`grid.png`, `commands.png`, `pane-menu.png` and `history-hover.png` show FACT
0.3.3 running in real Windows ConPTY sessions. The original capture drove eight
independent PowerShell processes, the actual keyboard and mouse controls, and
recorded the resulting terminal cell grid. The PNG renderer preserves that
content and its colors using Consolas and adds only black padding, with no
invented window frame. PIDs and shell versions reflect the capture machine. The
demo deliberately configures a `Ctrl+B` prefix for its driven input; the default
is `Ctrl+Space`.

The pane menu shown here is now opened with `Shift`+right-click, because plain
right-click copies or pastes. The menu contents and the rest of the workspace
layout are unchanged.

The history example generates numbered lines locally. No model request, agent
conversation, clipboard content or personal session is used.

`grid-4.png`, `agents.png`, `video-wallpaper.webp` and `see-through.webp` show
FACT 0.7.0 in Windows Terminal on the maintainer's machine: plain screenshots,
and two screen recordings cut to a few seconds and encoded as animated WebP
(GitHub plays them inline; they are far smaller than GIFs). The video clip joins
two moments of the same recording so no unrelated terminal output appears.

These are reviewed documentation assets, not generated by the test suite.
Update them manually only when the visible workspace changes, and review each
image before committing it.
